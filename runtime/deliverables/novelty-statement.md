# Novelty statement (draft)

PromptLang checks the declared input and output types of a prompt chain before a chain is run. Its planned type limits let the checker compare text values with different maximum lengths. Generated code also checks each model answer while the chain is running, because a model can return something different from its declared output. Together, the static check and runtime guard make the chain's declared contracts useful both before and during a run.

This is a project contribution statement, not a claim that no other tool has similar features. The comparison and citations should be completed with Person A's checked literature survey before the presentation.
